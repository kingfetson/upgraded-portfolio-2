# Professional Portfolio - Minimal Corporate Theme

A clean, elegant, ATS-friendly portfolio theme designed for corporate professionals, executives, and job seekers.

![Corporate Portfolio Preview](https://via.placeholder.com/800x450?text=Professional+Portfolio+Theme)

## ✨ Theme Features

- **🏢 Corporate Design** - Clean white background, elegant typography, professional layout
- **📄 ATS-Friendly** - Optimized for applicant tracking systems and recruiters
- **✍️ Elegant Typography** - Inter font for readability, clean hierarchy
- **📊 Complete Resume Sections** - Experience, Education, Skills, Certifications
- **🖨️ Print Ready** - One-click print / save as PDF functionality
- **💾 Auto-save** - All changes persist in browser storage
- **📤 Export/Import** - Backup and restore your resume data
- **📱 Responsive** - Works perfectly on all devices
- **🎯 Recruiter Optimized** - Clear sections, scannable content, professional layout

## 🚀 Quick Start

1. **Download** all files (`index.html`, `style.css`, `script.js`)
2. **Open** `index.html` in your web browser
3. **Edit** your information using the sidebar controls
4. **Export** as PDF using the print button (Ctrl+P / Cmd+P)

## 🎨 Design Philosophy

### Typography
- **Headings**: Inter Semi-bold (clean, modern)
- **Body**: Inter Regular (highly readable)
- **Hierarchy**: Clear visual distinction between sections

### Color Palette
- **Primary Text**: #1a1a1a (high contrast)
- **Secondary Text**: #4a4a4a (readable)
- **Accent**: #2c3e50 (professional navy)
- **Background**: #ffffff (clean white)
- **Borders**: #e5e5e5 (subtle separation)

### Spacing & Layout
- Generous white space
- Two-column resume layout
- Clear section separation
- Consistent padding and margins

## 📄 ATS Optimization Notes

This theme is designed to be ATS-friendly:

✅ **Standard Section Headings** - Uses conventional section titles
✅ **Clean HTML Structure** - No complex tables or columns
✅ **Text-based Content** - No images for critical information
✅ **Print-friendly CSS** - Optimized for PDF rendering
✅ **Standard Fonts** - Uses web-safe fallbacks
✅ **No Fancy Formatting** - Avoids elements that confuse parsers

## 🖨️ Print / PDF Export

To save your resume as PDF:

1. Click the **"Print / Save as PDF"** button
2. Or use keyboard shortcut: `Ctrl + P` (Windows) / `Cmd + P` (Mac)
3. Select "Save as PDF" as the destination
4. Adjust margins if needed (recommended: default or minimum)
5. Save your professional resume
